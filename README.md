# Aca-Schedule（アカ・スケジュール）

アカペライベントの本番・リハーサル日程を作成、共有する Web アプリです。複数日、クール、メンバーの掛け持ち、出演可能時間を考慮してタイムテーブルを編集できます。

[公開サイト](https://aca-schedule.vercel.app/)

## 主な機能

- **バンド管理:** バンド名、メンバー、演奏時間、出演回数、衣装、日別の出演可能時間を管理。CSV インポートにも対応します。
- **出演可能時間:** 15 分刻みのグリッドをドラッグして選択し、選択範囲の端は分単位で調整できます。リハーサルには通常の時間帯と予備の時間帯を設定できます。
- **タイムテーブル編集:** 本番・リハーサルと日付を切り替え、クール内やクール間でカードをドラッグして配置できます。開始時刻、転換時間、固定カード、カスタムイベントも扱えます。
- **自動配置と確認事項:** 出演可能時間、日別の終了時刻、メンバーの重複などを評価して配置を支援します。連続出演はクールごとに判定します。予備出演可能時間を使ったリハーサルも確認事項に表示します。
- **カスタム列:** 列の追加、並べ替え、セル結合に対応します。列ごとに一般公開するか選択でき、初期状態では公開しません。
- **共有:** 一般公開ページ `/share/:eventId` には公開対象の情報を表示します。関係者ページ `/stakeholder/:eventId` は設定したパスワードで開き、関係者向けの情報を表示します。閲覧データはサーバー API 経由で取得します。
- **アカウントと共同編集:** メール確認または Google アカウントでログインし、イベントのオーナーが共同編集者を招待できます。

## 技術構成

- フロントエンド: React、TypeScript、Vite、Tailwind CSS、dnd-kit
- データ・認証: Firebase Authentication、Firestore、Firebase Admin SDK
- API・配信: Vercel Functions、Vercel
- テスト: Vitest、Node.js の API テスト

## ローカル開発

```bash
npm ci
npm run dev
```

Firebase 接続に必要な環境変数は各自の `.env.local` に設定してください。このファイルは Git 管理対象外です。フロントエンドの開発サーバーと Vercel Functions の実行環境は別です。API を含めて動作確認する場合は、対応するサーバー環境も用意してください。

```bash
npm run build
npm test
npm run lint
```

`npm run build` は、API が使用する自動配置・関係者進行表示のモジュールを `api/_lib/` に生成してから TypeScript と Vite をビルドします。`dist/`、テストキャッシュ、添付資料などの一時ファイルは Git 管理対象外です。作業用の一時ファイルは `tmp/` に置きます。

## API

認証済みユーザー向けの API で、バンド管理やイベント操作を自動化できます。Firebase ID トークンまたはスコープを設定したユーザー API トークンを使用します。エンドポイント、入力形式、認可の詳細は [API 仕様](docs/api.md) を参照してください。

```bash
npm run test:api
```

上記の API テストには実行環境と認証設定が必要です。単体テストとビルドはそれらなしでも実行できます。
